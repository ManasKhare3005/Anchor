## Calibration

Calibration set: fixtures + 90 confirmed real-site labels. Thresholds are chosen to find the most features with **zero** wrong matches on that set (a safety margin under the 1% / 5% targets; tuning up to the targets overfit). Leave-one-site-out re-tunes without each site in turn and scores that site, to show how the thresholds do on a site they never saw.

Chosen: sure ≥ 0.60 with gap ≥ 0.15; fairly ≥ 0.40 with gap ≥ 0.12. These are the matcher's built-in defaults.
